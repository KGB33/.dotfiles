# vibes

My Skills

## Use with Pi

Pi discovers every `skills/<name>/SKILL.md` when this repository is configured as
a skill source. No package manifest or extension is required. Skills load on demand
from their frontmatter and are also available as `/skill:<name>` commands when skill
commands are enabled.

For the manual Neorg process:

1. Set `NEORG_WORKSPACE_PATH` to the workspace containing `maps/` if the host did
   not already provide that workspace.
2. Run `/skill:cartographer` to create and review one feature map.
3. Run `/skill:scout` to implement and independently review one ready map node.

Each Scout invocation stops after one node.
